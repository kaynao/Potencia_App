# Potencia_App

🍇 Açaí — Sistema de Gestão

Sistema web desenvolvido para auxiliar no gerenciamento e nas operações de um estabelecimento de Açaí.

📖 Sobre o projeto

O Açaí — Sistema de Gestão é um projeto desenvolvido com o objetivo de facilitar o gerenciamento de um estabelecimento de Açaí, centralizando informações e funcionalidades importantes em uma única aplicação.

A ideia é proporcionar uma interface simples, intuitiva e prática para auxiliar no controle das operações do negócio.

O projeto também contempla o encaminhamento dos clientes para o site próprio do Açaí, aproximando o sistema de gestão da experiência de compra do cliente.

✨ Funcionalidades
🛒 Gerenciamento de vendas
📦 Gerenciamento de produtos
📋 Organização do cardápio
👥 Gerenciamento de clientes
📊 Visualização de informações e estatísticas
🌐 Integração/encaminhamento para o site próprio do Açaí
📱 Interface voltada para utilização em diferentes dispositivos

🚧 O sistema encontra-se em desenvolvimento e novas funcionalidades poderão ser adicionadas.

🎯 Objetivo

Desenvolver uma solução tecnológica capaz de tornar o gerenciamento de um estabelecimento de Açaí mais organizado, rápido e acessível, reduzindo processos manuais e centralizando as principais informações do negócio.

🚀 Executando o projeto
Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

Node.js
npm
Instalação

Clone o repositório:

git clone https://github.com/kaynao/Potencia_App.git

Entre na pasta:

cd Potencia_App

Instale as dependências:

npm install

Execute o projeto:

npm run dev

Após iniciar, o terminal irá informar o endereço local para acessar a aplicação.
